# Локальный браузерный режим

## Сценарий

1. Локальный HTTP-сервер слушает только `127.0.0.1`. Из страницы можно выбрать **уже существующий** `configs/gui_*.yaml`. Сам YAML остаётся текстовым источником настроек; произвольный путь через браузер не принимается.
2. Пользователь при желании задаёт фразу для тренировки. Она видна как подсказка на экране, но не подаётся в prior или декодер. Без фразы возможен свободный набор.
3. Матрица 6×6 подсвечивает строки и столбцы в перемешанном порядке. В медленном профиле вспышка длится 500 мс, интервал — 300 мс, два повтора. Один символ занимает около 19 секунд без задержки на декодирование. Параметры меняются правкой YAML или выбором другого профиля.
4. Пробел, нажатый во время вспышки, записывается как бинарный отклик на эту группу. Пробел вне вспышки игнорируется. Клавиша не вставляет пробел в текст напрямую; символ `␣` тоже выбирается матрицей.
5. После всех вспышек сервер строит правдоподобие для каждого символа с `response_hit` и `response_false_alarm` из YAML, объединяет его с символьным n-граммным prior существующим модулем Fusion и передаёт в SymbolDetector. При отсутствии сигнала или низкой уверенности символ не записывается и эпоха повторяется.
6. В интерфейсе видны основной текст, решение и три наиболее вероятных символа. Данные сессии и нажатия сохраняются локально в `runs/gui/`; остановка закрывает журнал и создаёт проверку целостности. Запросы к внешним сервисам не выполняются.

## Qwen

Кнопка «Предложить продолжение» использует локальный Qwen2.5-0.5B-Instruct GGUF через CPU-сборку `llama-cli`, **если** сервер запущен с `--qwen-model` и `--qwen-cli`. Она не участвует в быстром выборе символа: для этого используется n-граммный prior. Такое разделение сохраняет предсказуемое время реакции на вспышку. Модель не загружается из сети при работе сервера; файл должен существовать заранее.

## Запуск

```bash
.venv/bin/python -m eeg_speller.web.server --port 8765 --output runs/gui
```

Открыть `http://127.0.0.1:8765/`. Для Qwen добавить `--qwen-model /absolute/path/to/qwen2.5-0.5b-instruct-q4_0.gguf --qwen-cli /absolute/path/to/llama-cli`. CPU-сборка `llama.cpp` на macOS: `cmake -S llama.cpp -B llama.cpp/build-cpu -DGGML_METAL=OFF -DGGML_BLAS=OFF -DLLAMA_BUILD_TESTS=OFF -DLLAMA_CURL=OFF && cmake --build llama.cpp/build-cpu --target llama-cli -j 4`. Пример модели: [Qwen/Qwen2.5-0.5B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF). Скачать её следует отдельно; веса не входят в репозиторий.

## Границы режима

Нажатия клавиатуры — контролируемая имитация бинарной физиологической реакции, а не ЭЭГ. Время вспышки задаётся браузером, поэтому точность ограничена планировщиком страницы и частотой монитора. Прототип не подключает реальную шапку, не калибрует участника и не доказывает метрики ТЗ на людях.

# Проверка локальной интеграции физиологии

База: WaRotiFY/speller1p, operator-window, 56cac62. Проверка 13 октября 2026 года. Изменения остаются в отдельном локальном рабочем дереве.

## Браузерная проверка EDF

Генератор подготовил обучающую запись для «ажмтчя» и независимую тестовую запись для «кот» с восемью каналами при 256 Гц. Классификатор использовал Cz, Pz, P3, P4. Интерфейс запущен на 127.0.0.1:8767 в macOS-песочнице.

В интерфейсе намеренно было выбрано другое задание — «яяя». Языковая модель была отключена. Без нажатий пробела за три эпохи появился текст **«кот»**. Таким образом, интерфейс не скопировал цель задания. Приложение читало тестовый EDF и обученную модель; файл ожидаемого ответа в декодировании не участвует.

| Измерение | Результат |
|---|---|
| Декодированных эпох | 3 |
| Принятых меток вспышек | 72 из 72 |
| Максимальная оценка неопределённости часов | 0,65 мс |
| Максимальное расхождение относительных времён EDF/кадров | 8,4 мс |
| Проверка целостности сессии | complete=true, ошибок нет |

Это измерения программной синхронизации воспроизведения, а не физической задержки монитора или точности распознавания человеческой ЭЭГ.

Повторная проверка на окончательном браузерном пути: сгенерирована новая тестовая запись для «мир» с другим шумом (`seed=41786`). В интерфейсе выбран свободный набор без цели, БЯМ выключена. Без клавиатурных ответов появился текст **«мир»**; сессия завершилась по концу EDF. Приняты 72 метки, оценка неопределённости часов до 0,75 мс, расхождение кадров с EDF до 8,1 мс, целостность подтверждена.

После окончательной проверки отказов интерфейс перезапущен и ещё раз обработал «мир»: 72 метки, оценка неопределённости до 0,95 мс, расхождение до 4,7 мс, 99 событий, три завершённые эпохи, ошибочно прерванных эпох нет. Сеанс `20261013T191446Z_P-LIVE_live_36c2` закрыт корректно. Интерфейс оставлен работающим.

## Автоматические проверки

Проверяются декодирование случайно выбранной строки из независимой тестовой волны, отсутствие уверенного ответа после удаления P300-компоненты, отсутствующие/повторные/несвоевременные маркеры, aliases и отсутствие каналов, несовместимость модели с обработкой, форма выходного контракта и сохранение прежнего клавиатурного режима. Отдельный тест использует настоящий liblsl на localhost: передаёт отсчёты, проверяет выбор каналов, перевод mV→V, временную метку LSL-маркера и сохранение сырого сигнала.

Итог: **30 passed**, 8,55 секунды, Python 3.12 в отдельном `.venv`. Проверка `git diff --check` пройдена. Отдельно проверено, что даже prior 99,9 % и режим детектора `label` не могут ввести символ при отсутствии целевой P300-реакции.

Человеческий эксперимент и подключение физической шапки в эту проверку не входят.

## Изоляция

Проверены ограничения рабочего серверного процесса: чтение собственного временного файла в домашней папке вне проекта, запись вне `runs/configs` и соединение с внешним тестовым адресом были отклонены с `PermissionError`. Интерфейс продолжает работать через localhost. На момент локальной проверки GitHub не изменялся; этот отчёт описывает проверку перед публикацией.
